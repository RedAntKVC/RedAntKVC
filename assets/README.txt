Place the following image assets in this directory:

- icon.png           (1024 x 1024)  — App icon (iOS and Android square icon)
- splash.png         (1284 x 2778)  — Launch / splash screen image
- adaptive-icon.png  (1024 x 1024)  — Android adaptive icon foreground layer
- favicon.png        (32 x 32)      — Web favicon
- notification-icon.png (96 x 96)   — Android push notification icon (white on transparent)

Background colour for splash and adaptive icon: #0f172a (dark slate)

Tip: Use https://www.appicon.co or Figma to generate all sizes from a single master icon.
